# 5.4.0 验证及已知限制

本次为三平台兼容性验证交付，发布为GitHub Pre-release。版本号表示统一源码/二进制基线，不表示已获得厂家认证或完成全部原生CAD验收。

## 本次已验证

- 从固定快照构建12组：AutoCAD五组、浩辰两组、中望五组，版本均5.4.0.0，全部零错误。11组零警告；浩辰2026有1项既有WindowsBase引用冲突MSB3277，须在对应宿主复核。
- 72份业务源码与此前已通过的尺寸一致性及中望移植回归基线逐字节一致。本次为统一发布只更新版本元数据，不额外修改运动学、包络或播放逻辑。
- 最终DLL只读PE元数据检查306项通过：x64、目标框架、对应宿主API、八个命令各注册一次，且没有混入其他CAD宿主引用。
- 既有真实源码链接测试包含尺寸819、货车表单2196、搬运车表单57813、消防表单93873、P1防回归40090、消防/播放数据1042和动画生命周期169项明确计数断言，合计196002，另有完整历史几何、搬运车21类场景及预览测试。中望副本也链接其真实核心/表单源码运行，未以另一份自写算法替代生产代码。
- 测试包含轻量CAD API替身、内存窗体构造和离屏绘图。原生CAD进程、NETLOAD、Jig/GPU渲染、每个SP补丁及文档切换的实际行为仍需现场验收，不能把断言次数理解为在12个CAD中实测了相同次数。

## 适用范围

当前为Windows64位；中望2022—2026须支持.NET的专业/相应行业版，不含标准版、Linux、鸿蒙、32位和2027 Beta。AutoCAD2025/2026较新.NET10宿主补丁应单独验收，不把旧补丁结果外推为全部兼容。

普通货车参数可能按总长估算；多轴按等效两轴运动学、1.35m轴组间距示意，不是厂家独立多桥模型。消防仅两轴普通前桥，历史窄车模板轮距1.40m是插件估算。搬运车通用模板非厂家认证；ISO仅作为集装箱尺寸参考。

二维几何不提供载重、轮胎侧偏/滑移、速度稳定性、坡度、悬吊摆动、净高或消防规范符合性结论，实际工程应复核设备资料和安全余量。

## 已知待完善项

- 静态/鼠标预览车轮转角仍使用既有符号估计，直行或倒车的轮胎朝向示意可能与采用记录轮角的动画不同；本次没有将该显示估算重写成逐帧精确曲率。
- 搬运车设备与远偏移箱体形成互不相交的安全区域时，现有取环策略可能只显示最大一环，不应将该特殊工况当成已完整校核。
- 旧横移接近90°的门限和能力开关仍依现有实现，接近门限的特殊角度应实测；本次未扩展极限工况定义。
- “自动图纸单位”依赖DWG元数据，元数据错误时可能错误缩放。使用者应手动选与实际图面一致的单位，本次不宣称自动判定能识别所有旧图。
- 旧图块不随选型自动重画；旧静态路线无快照不能回放。新校验可能明确拒绝旧不合理参数，不会静默换模板。
- 动画异常移除失败会安全保留原生对象引用，避免CAD悬挂指针，可能保留少量资源至CAD退出。TTSTOP或下次同文档播放可重试，不承诺异常下立即释放所有原生资源。

## 交付一致性

SHA256SUMS.txt列出交付DLL及必要依赖；BUILD_MANIFEST.json记录版本、目标框架和源码/二进制指纹，不包含CAD SDK。AutoCAD2018随System.ValueTuple及其许可/通知，其他运行时依赖清单保持与对应DLL同目录。

正式用于项目之前，请按附带AutoCAD/中望清单验收；浩辰可按相同命令、尺寸、单位和动画生命周期项目验收，并记录具体版本/补丁、DLL和完整异常。

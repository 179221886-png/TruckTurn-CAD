# 消防选型与轨迹回放

纳入5.4.0三平台交付。当前为对应API编译及离线回归通过，仍需原生CAD实机验收。

## 使用入口

- `FIREDRIVE` / `FIRE`：独立的两轴前桥转向消防车选型与连续驾驶。
- `TRUCKDRIVE`、`TRUCKTURN90`、`CARRIERDRIVE` / `CAR` 正常完成路线后可选 `P` 打开播放器；默认 `N`。
- `TTPLAY`：选择本版本新生成的完整轨迹块。`TTSTOP`：关闭回放并尝试清理临时车辆。
- 播放器：播放/暂停/停止/进度/0.5、1、2、4倍速/循环。不是 GIF 或视频导出。

消防支持范围先限定为两轴普通前桥转向。多轴消防车、后桥辅助转向不能把轴距相加后套用普通两轴模型。

## 参数与出处

消防窗口直接输入真实前后轴距、前悬、后悬和轮距：整车长＝前悬＋轴距＋后悬。车宽按含固定突出物的最大宽度考虑；消防示意图不会再额外把后视镜画到该宽度之外。车高只用于侧立面预览，不参与二维包络及净高校核。

通用两轴水罐的8.50×2.50×3.30m、轴距4.50m、前悬1.40m、后悬2.60m、轮距1.95m、转角38°全部是可编辑的设计假设，不是厂家或标准规定值。

中联 ZLJ5060TXFJY68 历史公开参数参考：长7.10m、宽1.93m、高2.90m、轴距3.815m。[原厂家历史页](https://sales-cloud.zoomlion.com/equipment/content/201508/821.html)、[同路径产品页](https://zoomlionmall.com/equipment/content/201508/821.html)，应按公告和批次再次核对。前悬1.10m、后悬2.185m、轮距1.40m、转角38°由插件估算，界面逐项区分。旧轮距估算1.50m会使允许转角内示意轮胎超出1.93m外宽，新模板采用1.40m并明确非厂家值，旧参数不静默覆盖。公开通道圆直径16m只用于解释口径，不直接反算车心半径或转角，也不承诺模拟与16m吻合。

[徐工JP62T5](https://www.xcmg.com/product/pro-detail-120000.htm)和[Rosenbauer RT](https://emobility.rosenbauer.com/en/download/3320/15318)仅用于展示多轴/后桥转向边界，当前禁止套模出图。消防车几何并非由集装箱ISO标准推导，不作厂家认证或消防规范通行结论。

## 数据与算法

复用既有两轴刚体的自行车运动学、交互驾驶和包络管线；消防窗口不经过货车按车长比例反推轴距的选型流程。消防选型及侧立面高度存在当前DWG独立记录 `TruckTurnFireParamsV1`，不覆盖货车选型或朝向。

每条结果块的扩展字典 `TRUCKTURN_PLAYBACK_V1` 保存其车型参数深快照、类别、来源说明、全部录制位姿和初始块变换。货车坐标为CAD单位的后轴中心；搬运车中心米坐标转换为CAD单位后保存。播放时重建车体与挂车，不重新运行驾驶求解或包络并集。

演示时间按位移/1.4m/s、航向变化及停车摆轮时长生成，不代表真实驾驶时间。平移线性插值，车身/挂车/轮角按最短角度插值，避免跨±π反转。实际倒行保留车头朝向，不按位移切线掉头。

编码为限定类型的XML参数＋二进制位姿＋GZip，外层长度/SHA256用于损坏检测（不是来源认证）。拒绝DTD、任意类型、NaN、坏枚举、错误时间及越界数据；单条最多200000帧，编码/解压各32MiB。Xrecord按127字节二进制分块保存。旧静态块不猜测还原，分解块可能丢失关联。

原生Polyline临时图元固定复用；WinForms主线程Timer约30Hz，只更新车辆图形，无逐帧DB写入、无包络计算、无每帧Regen。支持结果块平移、平面旋转及正向等比缩放；镜像、非等比缩放和3D倾斜拒播。

停止移除车辆、保留窗口；关闭窗/其他命令/切图/关图/插件退出停止Timer并解除事件。若宿主没有确认移除临时图形，保留原生对象强引用，避免释放后悬挂指针；`TTSTOP`或下次播放仅在所属图纸重试。该异常路径可能保留少量资源至退出CAD，不承诺异常情况下立即清空所有原生资源。

## 验证边界

源链接的消防参数、动画数据和旧P1回归用于离线算法验证；12组SDK编译仅代表API可编译。原生Transient显示、保存关闭重开、复制/变换块和跨图纸生命周期仍需对应CAD版本实机验收。统一打包和版本号不等于所有宿主均已完成验收。

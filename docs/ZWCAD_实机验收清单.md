# 中望CAD实机验收清单

当前是编译及离线回归后的测试版；不能把本表空项理解为已经实测通过。

## 环境与加载

- 记录CAD年份、完整VERNUM/SP补丁、专业/行业版、Windows版本及64位状态。Windows标准版、Linux、鸿蒙、32位和2027 Beta不在当前测试版范围。
- Windows系统具备.NET Framework4.7或以上。完全关闭并重启CAD，用NETLOAD仅加载该年份TruckTurn.ZWCADyyyy.dll，不混用AutoCAD/浩辰DLL，不复制ZwManaged/ZwDatabaseMgd进插件目录。
- 只将固定插件目录加入可信位置。不要关闭全局安全策略、安装来历不明补丁或绕过CAD许可。若有载入错误，保留完整异常和命令行日志。
- 分别确认TRUCKDRIVE、TRUCKTURN90、CARRIERDRIVE/CAR、FIREDRIVE/FIRE、TTPLAY、TTSTOP已注册。

## 参数与尺寸

- 新米图与毫米图各测一次；实际图形单位与选择一致。相同物理参数缩放应为1000倍，不能因自动单位选择让车异常大。
- 刚性预设、半挂预设、消防模板、搬运车：输入→确认→再打开不修改，重复三次不漂移；自定义高精度尺寸也需保持。
- 直线车体量取：刚性总长/宽、半挂牵引车全长/挂车全长/搭接后的组合跨度、轴距及轮胎位置均与参数口径一致。不要将带安全余量的黄色包络当成本体。
- 检查窄车、短车、净距不足及轮胎外伸：明确错误提示，不暗中放大或换回默认模板。
- 刚性3/4轴、挂车1/2/3轴显示与选型一致；这是等效两轴运动学，1.35m轴组间距只是示意，不是厂家认证数据。

## 交互、包络与图块

- 各车型左右转、直行、S形、倒车、多次切换B、Esc撤销、X出图；短路/长路都测试。
- 搬运车前桥/后桥/反相四轮/蟹行；蟹行直线包络不应出现周期锯齿。
- 仅首尾和全部节点两种车体选项；中间包络实时可见，内部重叠边不残留；只开必要层与全开各测一次。
- 大图中鼠标预览、逐次确认和长路径X收尾耗时应可接受。记录CPU、RAM、GPU及路径长度，不能凭离线结果宣称所有机器丝滑。
- 单次Undo、保存重开、块移动/旋转后保持几何；旧静态轨迹不因新选型自动改变。

## 动画与清理

- 新路线出图选择播放，或TTPLAY选择完整轨迹块。播放、暂停、拖进度、速度、循环、停止均测试；单姿态路线可预览且无除零。
- 半挂铰接角、搬运车蟹行和各轮姿态按记录回放，量取起止姿态一致。
- 切换文档、关闭文档、执行其他CAD命令、关闭播放器应移除临时图形，不留下实体或定时器。TTSTOP可安全重复执行。
- 比较播放前后模型空间实体数量；动画不应逐帧向DWG写实体或生成一串Undo记录。暂停时缩放/平移后检查画面刷新。
- 结果块等比缩放/平移/旋转后仍能回放；镜像、非等比缩放或3D倾斜按现有约束明确拒绝。
- 保存关闭重开后回放；没有快照的旧静态图块应明确提示重新生成，而非猜测动画。

逐年记录通过/不通过及截图。尤其动画涉及原生图形接口/GPU，各年编译成功不能替代此项验收。

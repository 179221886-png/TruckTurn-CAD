# AutoCAD 实机验收清单

本包的五组 AutoCAD DLL 已完成对应 Autodesk API 的编译验证，但没有在每个年份的 AutoCAD 宿主中运行。正式用于项目图纸前，请在空白测试图中逐组验收。

1. 确认 AutoCAD 年份及更新补丁，按根目录 `README.md` 对应表选择 DLL。2018 版同时保留 `System.ValueTuple.dll`；2025–2027 版保留随包的 `.deps.json`。测试图分别用米和毫米单位复核尺寸。
2. 运行 `NETLOAD`，确认不出现缺少程序集、目标运行时不兼容或安全加载错误。如果被安全加载拦截，只把插件文件夹加入受信任路径，不要长期关闭 CAD 的安全设置。
3. 运行 `TRUCKDRIVE`：放置车辆，绘制直行、左/右转、倒行、铰接车长路径；切换“仅首尾 / 全部节点”，检查实时包络、出图、撤销及再次运行。
4. 运行 `TRUCKTURN90`：检查刚性车与铰接车的车体、轮迹和外侧包络是否连贯，长路径结束时能否正常出图。
5. 运行 `CAR`（与 `CARRIERDRIVE` 等价）：分别测试前桥、后桥、反相四轮、蟹行及箱型选择。蟹行直线段应为直线包络，转弯包络不应有明显锯齿、尖刺或漏包。
6. 检查选型窗是否能打开、保存参数，并在关闭/重开图纸后按预期恢复；保存 DWG、关闭和重新打开，再核对图层与块。
7. 用FIREDRIVE/FIRE测试两轴消防车预设及自定义参数，复核真实轴距/前后悬与车宽轮胎外伸。不要将多轴/后桥转向消防车套入此模型。
8. 出图后选P或TTPLAY选完整新轨迹块，测试播放/暂停/进度/倍速/循环及TTSTOP；播放前后不应新增一串DWG实体。切图、关图、启动其他CAD命令及关闭播放器应清理临时车辆和计时器。
9. 半挂参数不改确认三次，尺寸不得缩水；分别量取牵引车、挂车及计入搭接后的组合跨度。极短车、净距不足、轮胎外伸等冲突应明确提示，不静默改值。

至少记录 CAD 完整版本号、所用 DLL 文件名、操作步骤、截图和异常文本。AutoCAD 2025 Update 1.4+、2026 Update 1.2+ 的 .NET 10 宿主应单独验收，不能仅凭早期 .NET 8 补丁通过就推定兼容。
